## Considerções sobre as IA's utilizadas

## KIRO

A IDE Kiro é uma plataforma de desenvolvimento de inteligência artificial que oferece uma variedade de ferramentas e recursos para criar, treinar e implantar modelos de IA. Tem a vantagem de registro de prompt automatizados, e como desvantagem, a criação de muito arquivos em .md com resumos e informações sobre os projetos, o que pode ser um pouco confuso para organizar e acessar posteriormente. E muitas vezes, desnecessário para o projeto. Consome muitos creditos e tempo d usuário, o que pode ser um problema para projetos maiores ou para aqueles com recursos limitados. Eu entendo como um grande desperdicio de tempo e recursos, e não é uma prática recomendada para projetos de IA. Para quem esta aprendendo, pode ser um pouo desgastante essa geração desnecessária de resumos e documentos a cada codigo criado ou modificado, e para projetos maiores, pode se tornar um grande problema de organização e gerenciamento de arquivos. É importante avaliar cuidadosamente as necessidades do projeto e os recursos disponíveis antes de decidir usar uma plataforma como a Kiro, e considerar alternativas que possam ser mais eficientes e adequadas para o projeto em questão.


## Claude Code
O Claude Code é uma plataforma de desenvolvimento de inteligência artificial que oferece uma variedade de ferramentas e recursos para criar, treinar e implantar modelos de IA. Ele é projetado para ser acessível tanto para iniciantes quanto para profissionais experientes, permitindo que os usuários criem soluções de IA personalizadas para atender às suas necessidades específicas. Ele tem a vantagem de ser uma plataforma de desenvolvimento de IA fácil de usar, com uma interface intuitiva e recursos de arrastar e soltar que facilitam a criação de modelos de IA.
Tem varios recursos disponiveis no GitHub como skills prontas que ajudam na criação de agentes. No entanto, ele pode ter limitações em termos de recursos e funcionalidades em comparação com outras plataformas de desenvolvimento de IA, como porexemplo, o registro de prompts automaticos, o que pode ser uma vantagem para alguns usuários, mas pode ser um problema para outros, dependendo das necessidades do projeto. É importante avaliar cuidadosamente as necessidades do projeto e os recursos disponíveis antes de decidir usar uma plataforma como o Claude Code, e considerar alternativas que possam ser mais eficientes e adequadas para o projeto em questão. O Claude por ser mais objetivo e assertivo, tente a ser mais eficiente e economico, o que pode ser uma vantagem para projetos maiores ou para aqueles com recursos limitados, mas pode ser um desafio para aqueles que estão aprendendo ou que precisam de mais suporte e orientação durante o processo de desenvolvimento de IA.

## Conclusão 

Começei meu desenvolvimento com o KIRO, no entanto ele não foi eficiente, para um projeto E2E, ele precisa de microgerenciamento de tarefas, micro comandos e prompts bem amarrados para ele não fazer nada alémdo escopo. Ainda sim, existe grande chances de ele se disperssar com atividades desnecessárias. Mas para o registro de prompts autmaticos, ele é muito bom, e pode ser uma vantagem para quem precisa de um registro detalhado do processo de desenvolvimento de IA. No entanto, para projetos maiores ou para aqueles com recursos limitados, o Claude Code pode ser uma opção mais eficiente e econômica, embora possa exigir mais suporte e orientação durante o processo de desenvolvimento de IA. Em última análise, a escolha entre KIRO e Claude Code dependerá das necessidades específicas do projeto e dos recursos disponíveis, e é importante avaliar cuidadosamente as vantagens e desvantagens de cada plataforma antes de tomar uma decisão.Recomendo o Kir para pequenos projetos ou para aqueles que precisam de um registro detalhado do processo de desenvolvimento de IA, e o Claude Code para projetos maiores ou para aqueles com recursos limitados, mas que precisam de uma plataforma de desenvolvimento de IA fácil de usar e eficiente.
